───────────────────────────────────────────────────────────────────────────────
PASSO 1️⃣  PREPARAR OS FICHEIROS
───────────────────────────────────────────────────────────────────────────────

Descarregou do Claude:
  ✅ index.html (a aplicação)
  ✅ README.md (documentação)

Guarde num local seguro (ex: Desktop/Projetos/acessibilidade)


───────────────────────────────────────────────────────────────────────────────
PASSO 2️⃣  CRIAR CONTA NO GITHUB (se não tiver)
───────────────────────────────────────────────────────────────────────────────

1. Abra: https://github.com
2. Clique em "Sign up" (canto superior direito)
3. Preencha:
   📧 Email: seu.email@cml.pt (ou pessoal)
   🔑 Password: algo seguro (ex: A1b2C3d4!Forte)
   👤 Username: papl-cml (ou outro à escolha)
4. Clique "Create account"
5. Confirme no email (abra a caixa de correio)


───────────────────────────────────────────────────────────────────────────────
PASSO 3️⃣  CRIAR REPOSITÓRIO NOVO
───────────────────────────────────────────────────────────────────────────────

1. Depois de logged in no GitHub, procure o ➕ (canto superior direito)
2. Clique → "New repository"
3. Preencha:
   
   Repository name: acessibilidade-pedonal
   Description: Levantamento de acessibilidade pedonal - CML
   Visibility: ✅ PUBLIC (importante!)
   
4. Clique em "Create repository"

🎉 Pronto! Repositório criado.


───────────────────────────────────────────────────────────────────────────────
PASSO 4️⃣  CARREGAR OS FICHEIROS
───────────────────────────────────────────────────────────────────────────────

1. Na página do repositório, clique em "Add file" (verde)
2. Selecione "Upload files"
3. Clique em "choose your files" ou arraste:
   
   Ficheiros a enviar:
   ✅ index.html
   ✅ README.md
   
4. Em baixo, clique em "Commit changes"

⏳ Aguarde 2-3 segundos enquanto carrega...

✅ Ficheiros enviados com sucesso!


───────────────────────────────────────────────────────────────────────────────
PASSO 5️⃣  ATIVAR GITHUB PAGES (O IMPORTANTE!)
───────────────────────────────────────────────────────────────────────────────

1. Na página do repositório, clique em "Settings" (aba no topo)
2. Na barra esquerda, procure "Pages" (sob "Code and automation")
3. Em "Source", configure:
   
   ☑️ Branch: main
   ☑️ Folder: / (root)
   
4. Clique em "Save"
5. Aguarde 30-60 segundos...

🎉 GitHub vai mostrar:
   "Your site is live at: https://seuusername.github.io/acessibilidade-pedonal"

COPIE ESTE LINK! É o seu URL final.

───────────────────────────────────────────────────────────────────────────────
  ⚙️ SE ALGO DER ERRADO
───────────────────────────────────────────────────────────────────────────────

❌ "Não aparece a página"
   → Aguarde 1-2 minutos (GitHub precisa de tempo)
   → Verifique em Settings > Pages se está ativo

❌ "Erro 404 Not Found"
   → Verifique se o ficheiro se chama "index.html" (exatamente)
   → Faça upload novamente

❌ "O GitHub Pages não aparece em Settings"
   → Certifique-se que o repositório é PUBLIC
   → Tente recarregar a página
